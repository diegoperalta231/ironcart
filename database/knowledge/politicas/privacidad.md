IronCart recopila solo los datos mínimos necesarios: nombre, correo y contraseña cifrada para la cuenta, y nombre, dirección, ciudad y teléfono opcional para el envío de un pedido. No pedimos ni guardamos datos bancarios.
Las conversaciones con Spot se guardan para mantener el contexto y mejorar el servicio; no compartas datos sensibles en el chat. Para limitar abusos se usa un identificador derivado de forma irreversible de tu dirección IP, no la IP en texto plano.
Los pedidos solo son visibles para la cuenta que los realizó.
